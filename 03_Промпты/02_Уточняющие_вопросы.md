# Промпт 2. Уточняющие вопросы клиенту

```text
На основе исходных документов и аналитической записки подготовь вопросы для интервью с клиентом.

Требования к вопросам:
- максимум 15;
- сначала вопросы, которые могут изменить границы MVP;
- не спрашивай то, на что уже есть прямой ответ в документах;
- формулируй по одному вопросу за раз;
- избегай жаргона и вопросов вида «какой функционал вам нужен?»;
- для каждого вопроса объясни, какое решение зависит от ответа;
- предложи варианты ответа, если клиенту так будет легче;
- раздели вопросы на: цель и метрики, пользователи, сценарий, данные, бизнес-правила, ограничения и приемка.

Затем прочитай `01_Исходные_документы/07_Ответы_клиента_на_уточнения.md`, сопоставь ответы с вопросами и заполни `02_Рабочие_шаблоны/02_Вопросы_и_решения.md`.

Если точного ответа нет, оставь вопрос открытым. Не придумывай решение молча: предложи безопасное допущение для MVP, укажи риск и способ проверки.
```
