# Промпт 5. Превратить согласованное ТЗ в план MVP

```text
ТЗ СОГЛАСОВАНО. Теперь работай как технический лидер и разработчик MVP.

Прочитай `ТЗ_MVP.md` и подготовь план реализации, но пока не создавай код приложения.

Ограничения:
- минимальный локальный стек;
- предпочтительно HTML, CSS и JavaScript без сборщика;
- без сервера, базы данных, авторизации и внешних API;
- данные черновика можно хранить только в localStorage;
- никаких секретов и реальных персональных данных;
- нельзя добавлять функции, отсутствующие в ТЗ.

Подготовь:
1. предлагаемую структуру файлов;
2. обоснование стека;
3. модель данных анкеты;
4. карту экранов и состояний;
5. псевдокод валидации;
6. псевдокод правил квалификации;
7. таблицу трассировки `FR/BR/AC → файл или функция → способ проверки`;
8. план из 5–7 коротких итераций, каждая заканчивается запускаемым результатом;
9. риски реализации и способы упростить решение без нарушения ТЗ.

Если в ТЗ есть блокирующее противоречие, остановись и задай вопрос. Если противоречий нет, закончи сообщением: «План готов, жду разрешения начать итерацию 1».
```
