# Промпт 6. Реализовать MVP

```text
Начинай реализацию согласованного MVP по утвержденному плану.

Работай итерациями. Для текущей итерации:
1. Перед изменениями коротко перечисли, какие требования `FR/BR/AC` реализуешь.
2. Изменяй только необходимые файлы.
3. Не добавляй функции вне ТЗ.
4. Сохраняй бизнес-правила в отдельных понятных функциях, а не внутри разметки.
5. Добавляй понятные сообщения об ошибках рядом с полями.
6. Обеспечь работу с клавиатуры, видимый фокус и корректные label.
7. Не используй реальные контакты, токены и внешние сервисы.
8. После изменений запусти доступные проверки и опиши ручной сценарий проверки.
9. Обнови таблицу трассировки требований.
10. Остановись после завершения итерации и покажи: что готово, как запустить, что проверить, что осталось.

Начни с итерации 1: каркас приложения, визуальные токены FORMA, модель состояния и переходы между шагами без реализации несогласованных функций.
```

После проверки первой итерации продолжайте короткими командами:

```text
Итерация 1 принята. Выполни следующую итерацию по плану с теми же правилами контроля объема и проверки.
```
