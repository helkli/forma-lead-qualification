# Эталон: краткое ТЗ на MVP FORMA

> Это не единственно верный вариант. Документ нужен для сверки логики после самостоятельной работы.

## Проблема

Менеджер FORMA не получает полные и сопоставимые данные о потенциальном проекте до первого звонка, потому что обращения приходят в разных каналах и собираются свободной перепиской. Из-за этого менеджер повторяет вопросы, а дизайнер тратит консультацию на позднюю квалификацию.

## Цель

Стандартизировать первичный сбор данных и дать менеджеру краткую карточку с объяснимым предварительным статусом.

## Метрики пилота

- не менее 80% тестовых анкет содержат площадь, услугу, срок и бюджет без дополнительной переписки;
- менеджер понимает содержание заявки не более чем за пять минут.

## Основной сценарий

1. Потенциальный клиент открывает анкету.
2. Заполняет обязательные поля по шагам.
3. Видит прогресс и понятные ошибки.
4. Проверяет сводку и подтверждает корректность.
5. Получает нейтральное сообщение об успешной отправке.
6. Менеджер видит итоговую карточку, предварительный статус и причины.
7. Менеджер копирует карточку в рабочий чат и принимает решение вручную.

## Must-функции

- адаптивная пошаговая анкета;
- обязательные поля и валидация;
- индикатор прогресса;
- экран проверки ответов;
- прозрачный расчет одного из трех статусов;
- причины статуса только в менеджерской карточке;
- копирование карточки;
- сохранение и восстановление черновика в localStorage;
- очистка черновика после успешного завершения;
- повторное заполнение новой заявки.

## Поля

| Поле | Тип | Обязательное | Правило |
|---|---|---:|---|
| Имя | текст | да | 2–60 символов |
| Контакт | текст | да | 3–100 символов, тестовые данные |
| Тип объекта | список | да | квартира / дом / другое |
| Площадь | число | да | целое 10–2000 м² |
| Локация | список + уточнение | да | Москва / до 30 км / более 30 км / другой регион |
| Удаленный формат | да/нет | условно | спрашивается вне Москвы и 30 км |
| Услуга | список | да | варианты из ответов клиента |
| Срок начала ремонта | список | да | 0–3 / 4–9 / 10–18 / более 18 месяцев / не знаю |
| Бюджет | список | да | диапазоны из ответов клиента |
| Кто принимает решение | список | нет | один / совместно / другое |
| Комментарий | текст | нет | до 1000 символов |
| Подтверждение корректности | checkbox | да | должно быть отмечено |

## Упрощенное дерево статусов

### Не наш формат

Хотя бы одно явное условие:

- выбрана только разовая консультация;
- бюджет `до 90 тыс. руб./м²`;
- объект дальше 30 км или в другом регионе и клиент не готов к удаленному формату.

### Приоритетная

Все условия одновременно:

- площадь от 45 м²;
- Москва или до 30 км от МКАД;
- услуга `полный дизайн-проект` либо `дизайн-проект и комплектация`;
- старт ремонта не позднее девяти месяцев;
- бюджет `120–180 тыс.` или `более 180 тыс. руб./м²`.

### Нужно уточнить

Все остальные, неизвестные и пограничные сочетания. Статус сопровождается перечнем причин, например: «бюджет не определен», «площадь менее 45 м²», «услуга не выбрана окончательно».

## Не входит

CRM, сервер, база данных, авторизация, уведомления, PDF, загрузка файлов, точный расчет цены, выбор дизайнера, аналитика, публичный запуск и юридические документы.

## Минимальные критерии приемки

1. При пустом обязательном поле переход дальше блокируется и показывается конкретная ошибка.
2. При ширине 360 px отсутствует горизонтальная прокрутка.
3. После обновления страницы введенный черновик восстанавливается.
4. После завершения черновик удаляется.
5. Для данных L-008 получается статус `Приоритетная` с объяснением.
6. Для данных L-002 получается статус `Не наш формат` с объяснением.
7. Для данных L-005 получается статус `Нужно уточнить` с причиной про бюджет.
8. Клиентский экран завершения не содержит слов `отказ` и `неподходящий`.
9. Итоговая карточка содержит все обязательные ответы, статус и причины.
10. Кнопка копирования помещает карточку в буфер либо показывает понятную инструкцию при недоступности API.
11. Все интерактивные элементы доступны с клавиатуры и имеют видимый фокус.
12. Приложение не отправляет сетевые запросы и не содержит ключей или токенов.
