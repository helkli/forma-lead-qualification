# Ограничения и доступные материалы

## Срок и формат пилота

- первый работающий вариант нужен за один учебный спринт;
- демонстрация проходит локально в браузере;
- пилот проверяют 5–7 знакомых потенциальных клиентов;
- интерфейс должен работать на телефоне и компьютере.

## Технические ограничения MVP

- без платного хостинга;
- без серверной части и базы данных;
- без авторизации;
- без реальной отправки писем и сообщений;
- без интеграции с CRM;
- без загрузки файлов;
- без генерации PDF;
- без внешних AI API;
- только HTML, CSS и JavaScript либо другой столь же простой локальный стек, если исполнитель обоснует выбор.

## Данные и безопасность

- использовать только вымышленные данные;
- не добавлять в репозиторий токены, пароли или API-ключи;
- не запрашивать паспортные, платежные и иные чувствительные данные;
- телефон/Telegram нужен в форме, но для демонстрации используются тестовые значения;
- предварительный статус является подсказкой менеджеру, а не автоматическим отказом клиенту.

## Доступные материалы

- цвет акцента `#C86B4A`;
- логотипа в пригодном формате пока нет — в MVP использовать текст `FORMA`;
- фотографии интерьеров не предоставлены;
- юридические тексты и политика обработки персональных данных не согласованы, поэтому публичный запуск не входит в MVP.

## Браузеры

- актуальные версии Chrome, Edge и Safari;
- минимальная ширина экрана — 360 пикселей.
